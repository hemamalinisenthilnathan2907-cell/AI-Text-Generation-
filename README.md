## AI Text Generator

#A simple web-based AI Text Generator that generates text from a user-provided prompt.

## About

#This project uses a pretrained Transformer language model with a simple Streamlit interface. 
#Users enter a prompt, and the AI generates a continuation.

## Features

#Simple prompt input
#AI text generation
#Generate Text button
#Loading message
#Generated text display
#Model caching

## Technologies

#Python
#Streamlit
#Hugging Face Transformers
#PyTorch
#Qwen Language Model

## How It Works

User enters prompt 
        ↓
Streamlit receives input 
        ↓ 
Qwen Model processes prompt
        ↓ 
AI generates text 
        ↓ 
Generated text is displayed

## Installation

#pip install -r requirements.txt

## Run

#streamlit run app.py
